# ZENZA Hair Studio — Luxury Atelier of High Hairdressing

A luxury web application for **ZENZA Hair Studio**, built with **React.js**, **Tailwind CSS**, and **Vite**.

## ✨ Features

- **Cinematic Atelier Home**: Full-bleed hero, philosophy, curated signature services, and testimonials.
- **Interactive Before / After Slider**: Draggable craftsmanship comparison slider.
- **Curated Services Menu**: Category filtering (*Cuts, Color, Texture, Scalp Spa, Haute Bridal, Grooming*).
- **Master Stylists & Brand Story**: Master artist roster and botanical luxury values.
- **Editorial Archive Gallery**: Filterable 12-look showcase with detailed view.
- **Dual Sanctuary Concierge**: Dynamic toggle between Mumbai (*Altamount Road*) and New Delhi (*The Manor*).
- **5-Phase Booking Wizard**:
  - Atelier locale switcher
  - Dynamic multi-service selection with live pricing and duration calculator
  - Master artist selection
  - Date & time scheduling
  - Confidential guest dossier
  - Live sticky ledger with GST (18%) and holding deposit (20%) calculation
  - Instant reservation confirmation modal

---

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS 3
- **Typography**: Google Fonts (*Playfair Display* & *Manrope*)
- **Icons**: Google Material Symbols Outlined

## 🚀 Getting Started

### 1. Clone the repository:
```bash
git clone https://github.com/mnataraj2006/zenza.git
cd zenza
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```
